# Lessons

One line per bug fix or correction: `- <what went wrong> → <the rule that prevents it>`

- Brief allowed 2–4 nodes per row on a 3-lane map → map rows have 2 to 3 nodes (brief §6).
- Brief didn't say whether a Drop Song's own Flow gain survives the Drop → the Drop resolves last; Flow is always 0 after a Drop card (brief §3).
- Brief's Anthem wording let a non-Anthem song use up the bonus → the first Anthem-keyword song each turn gets it; other songs never use it up (brief §5).
- Four Hip-Hop starter songs shared the name Block Party and burned each other out → starter songs meant to be played together get distinct names (brief §5).
- Brief didn't define quitting mid-fight → resume at the start of the current turn from a turn-start snapshot (brief §6).
- Brief didn't say whether Loyalty blocks Ad costs → Loyalty absorbs rival steals and nothing else (brief §3).
